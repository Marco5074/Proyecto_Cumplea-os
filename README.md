# Cumpleaños de Nataly ♡

Página web interactiva de cumpleaños hecha con HTML, CSS y JavaScript.

## Cómo usarla

1. Abrí `index.html` en el navegador.
2. Colocá las fotos definitivas en `assets/images/`.
3. Reemplazá los archivos `foto-1.jpg` hasta `foto-6.jpg`.
4. Para publicarla, subí la carpeta a un repositorio de GitHub y activá GitHub Pages.

La princesa predeterminada es Mulan.
